Status Kontrak Manager · Fase F0 · v1.0

Pasang web app uji

F0 hanya memastikan aplikasi bisa dibuka dari jaringan kantor sebelum fitur dibangun. Butuh sekitar 10 menit. Setelah lulus, file ini diganti dengan aplikasi lengkap di F1 dengan cara yang sama.

Yang dicek halaman uji

Halaman Google Apps Script terbuka dari jaringan kantor
Browser bisa memanggil server (google.script.run)
Font Google termuat, atau aplikasi perlu memakai font sistem
Server bisa memanggil Web App lain, syarat script penerima di F4

Langkah

  1. Buka project baruLogin dengan akun Gmail khusus FF, buka script.google.com → New project. Ganti nama project (kiri atas) menjadi Status Kontrak Manager.
  2. Tampilkan file manifestKlik ikon roda gigi Project Settings → centang Show "appsscript.json" manifest file in editor.
  3. Tempel ke 2 file terpisahKembali ke Editor (ikon <>). Di panel kiri ada dua file. Klik appsscript.json → Ctrl+A → hapus → tempel hasil Salin appsscript.json. Lalu klik Code.gs → Ctrl+A → hapus → tempel hasil Salin Code.gs. Simpan dengan Ctrl+S. Jangan digabung dalam satu file.
  4. Deploy sebagai Web appDeploy › New deployment → ikon roda gigi → Web app. Description: F0 · Execute as: Me · Who has access: Anyone with Google account → Deploy.
  5. Izinkan aksesKlik Authorize access → pilih akun FF → Advanced → Go to Status Kontrak Manager (unsafe) → Allow. Peringatan ini normal untuk script buatan sendiri.
  6. Uji dari PC kantorSalin Web app URL (berakhiran /exec). Buka di Chrome atau Edge di PC kantor, memakai jaringan kantor. Tunggu semua baris selesai, klik Salin hasil, lalu tempel di chat.

var F0_VERSI = '1.0';

function doGet() {
  return HtmlService.createHtmlOutput(PAGE_HTML.split('{{VERSI}}').join(F0_VERSI))
    .setTitle('SKM · Uji F0')
    .addMetaTag('viewport', 'width=device-width, initial-scale=1');

/** Dipanggil dari browser lewat google.script.run. */
function ping() {
  return {
    ok: true,
    waktuServer: Utilities.formatDate(new Date(), 'Asia/Jakarta', 'dd MMM yyyy HH:mm:ss'),
    zona: Session.getScriptTimeZone(),
    akunEksekusi: Session.getEffectiveUser().getEmail()
  };
}

/** Cek apakah server bisa memanggil Web App lain (syarat script penerima di F4a). */
function cekFetch() {
  try {
    var r = UrlFetchApp.fetch('https://script.google.com/home', { muteHttpExceptions: true, followRedirects: false });
    var code = r.getResponseCode();
    return { ok: code < 500, status: code };
  } catch (err) {
    return { ok: false, status: String(err && err.message || err) };
  }
}
